Bomberman Ultimate Universal v0.9

ONLINE
- Multiplayer still lets you choose Host Online Game or Join Online Game.
- No room code is required.
- Host waits in one shared match slot.
- Join automatically searches/retries until the waiting host is available.
- When connected, the host starts the match automatically.

SINGLEPLAYER SPECTATING
- When the human player dies, GAME OVER is shown without pausing the match.
- The surviving AI bots continue fighting each other.
- When one AI remains, the spectator banner announces the AI survivor.
- Press Enter to start another match.

All v0.8 features remain, including smarter multi-bomb AI, Ultimate Mode,
custom item drop rate, universal desktop/mobile controls, joystick, and online play.
